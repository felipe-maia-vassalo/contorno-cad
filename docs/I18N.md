# PT/EN language support - v0.2.1

Updated on 2026-11-01.

## Usage

Select **Português (PT)** or **English (EN)** in **Language / Idioma**, at the top of the app. English is the default; Portuguese remains selectable. The choice applies to the current session, and can be changed on any page.

Language is a presentation setting, separate from the project JSON and geometry signature. Switching language does not change dimensions, calibration, point coordinates, imported source data, the current CAD solid, or user-defined project names. Pending calibration-field values and pending JavaScript point edits are preserved. Prepare export files again to generate HTML in the selected language.

## Scope

Translated: page names, navigation, buttons, labels, guidance, warnings, application validation errors, profile columns, photo point-editor controls/status/help, plot legends/dimensions, and the on-screen geometry inspection.

Preserved: filenames, user data and notes not in the bundled catalog, text embedded in original photos, canonical enum values and JSON/report schema keys, and diagnostics supplied by third-party software. Historical Portuguese screenshots and original photographs have not been relabeled as English. The main README and user manual are now in English.

## Implementation

- `contorno_cad/i18n.py`: locale context, formatter callbacks with explicit locale binding, and display-only report labels.
- `contorno_cad/locales/en.json`: source-message-to-English catalog. Portuguese uses the source text; placeholders and numeric formatting are retained.
- `contorno_cad/ui.py`: explicit translations and stable widget keys. Numeric controls synchronize externally changed defaults without discarding pending edits just because a label changes.
- `contorno_cad/components/point_editor/index.html`: local PT/EN labels. A language render keeps pending points until a new project revision is received.
- CAD, image, profile, project, importer, and viewer modules translate application errors and plot text at presentation time; the internal source-message locale remains Portuguese unless a caller selects English. Installation CLI messages are English.

Translation does not add dependencies, API requests, or paid services. The existing dependency/license preparation still applies.

The component test uses Node.js when available; Node is optional and is not needed to run the app. Without Node, this test is skipped. Run:

```bash
python -m pytest -q
node tests/point_editor_i18n.cjs
```
